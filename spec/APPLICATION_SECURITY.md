# SAPI Application Security Profile v1

메시지 인증 뒤의 데이터 처리에도 같은 보안 계약을 적용한다. 이 프로파일은 특정 언어·웹 프레임워크·DB 제품에 종속되지 않는다.

## 기본 처리 계약

1. 인증된 주체를 키 관리 상태에서 얻는다. 요청의 `role`, `subject`, `is_admin` 값으로 인증 주체나 권한을 바꾸지 않는다.
2. 등록된 작업과 scope만 허용한다. 입력·출력 스키마, 객체 권한 정책, 주체별 요청 제한을 등록하지 않은 작업은 실행하지 않는다.
3. 입력은 닫힌 스키마로 검사한다. 선언되지 않은 필드·중첩 필드·타입 변환·NoSQL 연산자·prototype 필드를 거부한다.
4. 요청 제한과 재전송 예약은 모든 서버 프로세스에서 공유한다. 저장소 장애는 업무 실행 거절로 처리한다.
5. SQL은 신뢰한 설정으로 정의된 테이블·열과 별도 바인딩 값으로 구성한다. 객체 조회·수정·삭제 조건에 서버가 확인한 주체를 포함한다.
6. 외부 HTTP 요청은 등록된 목적지만 사용한다. DNS 결과를 검증하고 연결에 고정하며, 리다이렉트·내부 주소·임의 URL을 거부한다.
7. 응답도 닫힌 스키마로 검사한다. 비밀번호·키·관리자 전용 필드가 추가된 응답은 전송하지 않는다.
8. 공개 작업 목록을 생성하고 등록되지 않은 작업·명령·파일 경로·역직렬화 유형을 실행하지 않는다.

## 공통 스키마

모든 SDK는 동일한 JSON 스키마 부분집합을 실행한다. 외부 `$ref`, 정규식, 원격 스키마 조회, 타입 강제 변환은 제공하지 않는다. 입력과 출력의 루트는 `object`다. `properties`의 필드는 기본적으로 모두 필수이고 `optional` 배열로 선택 필드를 지정한다. 선언하지 않은 필드는 언제나 거부한다.

| type | 허용 설정 | 기본 제한 |
| --- | --- | --- |
| object | properties, optional | 필드 64개, 깊이 16 |
| array | items, minItems, maxItems | 항목 최대 16개, 설정 최대 64개 |
| string | minBytes, maxBytes, format, enum | UTF-8 최대 4,096바이트 |
| integer / number | min, max | 유한한 안전 숫자 범위 |
| boolean / null | 추가 설정 없음 | JSON 타입 그대로 |

`format`은 `text`, `identifier`, `uuid`다. 문자열 비교·enum·필드명 비교는 대소문자를 구분한다. `identifier`는 첫 글자가 영숫자이고 이후 영숫자·밑줄·마침표·콜론·하이픈인 ASCII 문자열이다. `uuid`는 소문자 정규 UUID다. `text`는 NUL/제어 문자를 허용하지 않으며 탭·개행·CR은 허용한다. 객체 필드명은 ASCII 문자로 시작하는 영숫자·밑줄이고 `constructor`, `prototype`, `__proto__`는 금지한다.

```json
{"type":"object","properties":{"id":{"type":"string","format":"identifier","maxBytes":64},"display_name":{"type":"string","maxBytes":120}}}
```

SQL 공격 문자열을 단순히 키워드로 검색해 제거하지 않는다. 적법한 문자열 값은 파라미터로 전달하며 SQL 명령으로 해석되지 않도록 한다. 키를 가진 악성 클라이언트와 다른 주체의 객체 ID도 시험 대상이다.

## 구현·검증 경로

- SDK 공통 스키마와 입력/출력 기본 검사, 작업 목록.
- 인증 상태에 묶인 영속 전역 요청 제한과 키 회전을 통한 우회 차단.
- 주체 조건을 고정한 SQL 작업·열 허용 목록·바인딩 실행.
- 선언형 애플리케이션 서비스의 안전한 DB/외부 HTTP 작업과 제한된 HTTP 수신.
- 실제 DB의 인젝션·권한 상승·객체 권한·과도한 필드 수정, DNS/리다이렉트 SSRF, 공유 제한, 잘못된 출력, 파싱 공격의 실행 시험.

알려지지 않은 미래 공격을 포함한 절대 안전성을 보장하는 프로파일은 아니다. 방어가 적용되는 실행 경로와 실제 공격 시험 결과를 함께 제공한다.
