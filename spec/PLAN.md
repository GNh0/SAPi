# State authority 구현과 검증

## 구성

- SQLite 영속 상태 저장소와 PostgreSQL 공유 상태 저장소.
- 원자적 재전송 예약, 글로벌 키 사용 한도, 만료·회전·폐기와 자동 회전.
- AES-GCM 키 보관, 외부 KEK, KEK 재포장, 인증된 감사 로그.
- mTLS 관리 API와 관리자·서비스·클라이언트 권한 분리.
- SDK key provider/replay provider 계약과 관리 서비스 어댑터.
- 배포 설정·키 발급 CLI·복구 절차·실제 패키지.

## 검증

1. 프로세스 재시작 후 재전송·폐기·사용량 유지.
2. 여러 프로세스/SDK의 경쟁 예약에서 단일 실행.
3. 저장 장애·잠금·관리 연결 장애에서 처리 중단.
4. 발급·자동/수동 회전·유예·폐기·KEK 회전과 권한 격리.
5. 실사용 키/KEK의 DB 평문 저장과 로그 노출 방지.
6. 실제 mTLS, 잘못된 인증서·역할·서비스·클라이언트 차단.
7. SQLite 및 PostgreSQL 통합 시험, 기존 적합성 검사와 패키지 소비.
8. 독립 소스 보안 검토·공격 재현·의존성 감사·발견 사항 수정 기록.
