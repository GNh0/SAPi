# SApi.Protocol

SAPI/0.1 message security for .NET Framework 4.6.2+, .NET Standard 2.0 and .NET 6+.
Register input/output schemas and authorization policies with `SecureServer`.
Use `StateClient` to connect persistent replay/admission storage and managed key issuance, rotation and revocation.
HTTP/HTTPS clients and scoped mTLS certificate validation are included.
See [installation and older runtime configuration](https://github.com/GNh0/SAPi/blob/main/docs/USAGE.md).
